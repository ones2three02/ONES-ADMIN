# ONES-ADMIN 项目状态与问题闭环审计

更新时间：2026-07-08  
当前版本：v0.0.146  
定位：长期架构负责人口径下的事实校准文档，用于区分已落地能力、部分闭环能力、未闭环事项和下一版本优先级。

## 1. 审计结论

ONES-ADMIN 已具备企业级后台管理系统的起步基座，但还没有达到“整体企业级闭环”的状态。当前系统可以继续演进为企业级 HRMS 平台，前提是后续版本优先治理架构边界、前端体验一致性、认证闭环、测试覆盖和发布证据，而不是继续只堆功能。

本次审计确认：

- 账号密码登录、Sa-Token 鉴权、权限菜单、系统管理、HRMS 一期、文件、字典、审计、Flyway、接口治理和 Jenkins 验证门禁已有代码基础。
- 飞书 OAuth、企业 SSO、短信登录、二维码扫码登录仍未完成后端闭环，目前只存在前端入口、配置提示和架构建议。
- 前端表格稳定高度只治理了员工、合同、系统用户等复杂分栏页，仍有 11 个业务 VXE 页面停留在 `height: auto`，目前只作为 WARN 输出。
- README 之前把“已完成能力、治理规范、部分实现和未来方向”写在同一段当前能力里，存在过度承诺风险。
- 后端 `ApiResourceService` 和 `HrEmployeeService` 已出现明显职责膨胀，需要在后续版本拆分服务边界。

## 2. 已闭环能力

### 2.1 认证与基础权限

- 账号密码登录接口 `/api/auth/login` 已落地。
- Sa-Token 负责签发与校验 `Authorization: Bearer <token>`。
- 角色、权限、菜单、用户角色关系、角色权限关系已经具备基础模型。
- 登录失败次数、临时锁定、最后登录时间已进入 `sys_user` 表结构。
- 登录失败最大次数和锁定时间已配置化，默认 5 次失败后锁定 15 分钟。

### 2.2 系统基础能力

- 用户、角色、菜单、部门、数据字典、文件资产、审计日志已有基础接口和前端页面。
- 文件上传支持本地存储与 MinIO 存储类型切换，文件下载已进入业务归属授权链路。
- 操作日志、登录日志、TraceId、统一响应、统一异常和防重复提交已有基础实现。

### 2.3 HRMS 一期能力

- 岗位、职级、员工主数据、员工生命周期、合同、花名册导入导出、人力概览、员工档案抽屉和资料附件已有一期闭环。
- 员工读接口已接入角色数据范围第一阶段。
- 员工手机号、邮箱、证件号等敏感字段已做第一阶段脱敏治理。

### 2.4 工程化与治理证据

- Flyway 迁移脚本 V1-V8 连续，数据库迁移报告可生成。
- 接口资源治理、Manifest、Diff、发布门禁、治理评分和动作项已有基础能力。
- Jenkins 与本地验证入口统一收口到 `scripts/ci/verify.sh`。
- 版本一致性、仓库安全扫描、环境配置报告、前端布局报告、数据库迁移报告、接口治理报告、验证摘要和发布证据包已建立。

## 3. 部分闭环能力

### 3.1 前端登录页

已完成：

- 登录页已迁移为 ONES/1S 品牌视觉。
- 白天和夜间品牌图标资源已拆分。
- 飞书、企业 SSO、手机号入口已收敛为 icon 入口。
- 二维码入口已放到右上角角标。
- 未配置能力会提示管理员配置，不再伪造短信验证码发送。

仍需治理：

- 左侧品牌视觉信息密度仍偏高，不够符合成熟企业后台的克制风格。
- 右侧仍存在滑块验证码占位，真实安全策略尚未与后端风控闭环。
- 飞书、SSO、扫码和手机号登录入口只有前端引导，没有后端认证闭环。

### 3.2 前端表格稳定高度

已完成：

- HRMS 员工、HRMS 合同、系统用户已迁移到 `SplitListLayout`。
- 上述分栏页面的主表格已使用 `height: '100%'` 和 `autoResize: true`。
- `frontend-layout-report` 已能扫描布局治理状态。

仍需治理：

- 以下业务页仍为 `height: auto`，需要继续治理：
  - `web/playground/src/views/hr/document-warning/list.vue`
  - `web/playground/src/views/hr/job-grade/list.vue`
  - `web/playground/src/views/hr/position/list.vue`
  - `web/playground/src/views/hr/roster-import/list.vue`
  - `web/playground/src/views/system/api-resource/list.vue`
  - `web/playground/src/views/system/audit/list.vue`
  - `web/playground/src/views/system/dept/list.vue`
  - `web/playground/src/views/system/dict/list.vue`
  - `web/playground/src/views/system/file/list.vue`
  - `web/playground/src/views/system/menu/list.vue`
  - `web/playground/src/views/system/role/list.vue`
- 当前报告只将这些页面列为 WARN，没有阻断发布。

### 3.3 API 治理

已完成：

- 当前接口治理质量分为 100，接口权限缺口为 0。
- 写接口审计、防重复提交、公开接口访问策略已有规则化检查。

仍需治理：

- 当前接口治理报告显示 `BASELINE_REQUIRED`，说明 Manifest 基线快照尚未在运行环境正式归档。
- 接口治理服务内部职责过多，需要拆分扫描、治理、Manifest、Diff、发布门禁、报告聚合等边界。

## 4. 未闭环事项

### 4.1 飞书 OAuth 与企业 SSO

当前未实现：

- 后端飞书授权回调接口。
- 授权码换取飞书用户身份。
- 第三方身份与本地用户绑定表。
- OAuth `state` 后端校验和重放防护。
- 第三方登录成功后统一签发 Sa-Token。
- 登录审计中的第三方平台、外部用户 ID、绑定方式记录。
- Sa-Token 白名单中的第三方回调路径。

后续建议新增：

- `auth-provider` 或 `auth/thirdparty` 包。
- `ThirdPartyAuthProvider` 统一接口。
- `sys_external_identity` 表。
- 飞书 OAuth Provider 实现。
- 第三方登录回调接口和测试。

### 4.2 短信登录与扫码登录

当前未实现：

- 短信供应商配置。
- 验证码生成、发送、校验、限流和审计。
- 二维码登录会话状态、轮询接口、扫码确认流程。
- 移动端扫码确认页或 App 工作台免登闭环。

现阶段策略：

- 前端保留入口和未配置提示。
- 不模拟真实验证码发送。
- 不把二维码入口描述为已可生产使用。

### 4.3 字段级权限体系

当前只完成了员工敏感字段脱敏第一阶段。后续身份证、手机号、合同附件、薪资、绩效等敏感域需要统一字段级权限矩阵、授权查看审计和可配置脱敏策略。

### 4.4 部署环境矩阵

当前 Jenkins 只做验证门禁，不做部署。真实测试、预发、生产环境仍需补充：

- 环境变量矩阵。
- 密钥注入方式。
- 数据库迁移 dry-run。
- Redis、RabbitMQ、MinIO 连通性检查。
- 部署回滚策略。
- Jenkins 与 GitHub 分支策略。

## 5. 主要风险

| 风险 | 严重级别 | 说明 | 建议 |
| --- | --- | --- | --- |
| 文档过度承诺 | P0 | README 容易把规划当成已完成能力 | 将当前能力拆成已落地、部分闭环、规划中 |
| SSO 未闭环 | P0 | 前端有入口，后端无回调和绑定 | 先做设计和表结构，再做飞书 OAuth |
| 表格高度治理不完整 | P0 | 11 个业务页仍可能出现高度持续变小 | 分批治理并提高 CI 门禁 |
| 服务职责膨胀 | P0 | 大服务继续膨胀会影响维护和测试 | 拆分 HRMS 和 API 治理服务边界 |
| 测试覆盖不足 | P1 | E2E 和单测覆盖不够支撑完整 HRMS | 补前端业务页 E2E、后端服务边界测试 |
| Manifest 基线缺失 | P1 | 接口发布差异缺少正式基线 | 在运行环境发布接口 Manifest 基线快照 |

## 6. 推荐版本路线

### v0.0.147：前端表格稳定高度治理

目标：

- 优先治理接口资源、审计、文件、字典、岗位、职级、资料预警、花名册导入等 `height: auto` 业务页。
- 将 `frontend-layout-report` 的剩余自动高度页面数量纳入更严格阈值。
- 补充至少一个业务页 Playwright 或组件级验证。

非目标：

- 不引入新的 UI 框架。
- 不改变 Vben / Ant Design Vue 风格。
- 不做后端 SSO。

### v0.0.148：认证适配层设计与飞书 OAuth 基线

目标：

- 新增第三方登录设计文档。
- 新增外部身份绑定表迁移。
- 新增飞书 OAuth 回调接口契约。
- 补齐 Sa-Token 白名单治理和接口治理元数据。

非目标：

- 不把飞书权限直接映射为系统权限。
- 不在前端保存 App Secret。

### v0.0.149：HRMS 后端服务边界拆分

目标：

- 拆分员工主数据、任职记录、组织关系、生命周期和导出职责。
- 保持现有接口契约不变。
- 用后端测试证明行为不回退。

非目标：

- 不拆微服务。
- 不改变数据库主结构，除非发现明确字段缺陷。

## 7. 维护规则

- 后续每个版本必须在交付说明中标注“已闭环 / 部分闭环 / 未闭环”。
- README 只描述当前真实可用能力，不把规划项写入当前能力。
- 涉及 SSO、短信、扫码、字段权限、薪资、审批、部署的变更必须先有设计文档和迁移/回滚说明。
- 前端新增业务页必须默认满足表格稳定高度、加载态、空态、错误态和主动作引导。
- 后端新增业务能力必须同步考虑权限、数据范围、审计、TraceId、错误码、测试和接口治理元数据。
