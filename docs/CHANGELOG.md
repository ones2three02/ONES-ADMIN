# ONES-ADMIN 版本记录

## v0.0.149 - 2026-07-11

- 建立 `ThirdPartyAuthProvider` 适配层和飞书 Provider，后端生成授权地址并依次调用飞书应用访问令牌、用户访问令牌和用户信息接口，App Secret 不进入前端。
- 新增 OAuth state 与短期登录票据存储，正式环境默认使用 Redis Lua 原子消费，测试环境使用内存存储；state 和票据均具备过期与防重放测试。
- 新增 `/api/auth/providers`、飞书授权/回调、OAuth 票据兑换接口，外部身份校验成功后继续由 ONES-ADMIN 加载本地角色权限并签发 Sa-Token。
- 新增 V9 迁移 `sys_external_identity`，支持管理员预绑定、查询和停用外部身份；默认不按邮箱自动创建或绑定本地账号，未绑定身份明确拒绝登录。
- 登录日志增加认证方式、Provider 和外部身份引用，前端审计表格同步展示认证方式；飞书成功、未绑定、state 重放和票据重放均进入认证审计。
- 登录页保持现有 Vben / Ant Design Vue 风格和 icon 布局，飞书入口改由后端能力状态驱动，新增复用 Vben 认证布局的回调处理页。
- 本版本只在 H2 测试库验证 V1-V9 迁移，不连接或迁移真实 MySQL/Redis，不配置真实飞书应用，不执行部署；真实启用前需完成备份、回调白名单、Jenkins Credentials 和 Redis 联调。
- 产品版本递增至 `v0.0.149`。

## v0.0.148 - 2026-07-11

- 将系统数据初始化改为显式开关，正式运行默认不再创建演示管理员；启用初始化时必须从环境变量提供管理员密码，代码和正式配置不保留固定密码。
- 将登录失败次数更新改为数据库原子 SQL，补充并发失败测试，避免并发登录失败时计数丢失。
- 新增可切换 Redis/内存的账号与 IP 双维度登录限流，Redis 计数与 TTL 通过 Lua 原子更新；超过阈值返回 HTTP 429，并继续写入登录失败审计。
- 将 Swagger、OpenAPI 和 Actuator 纳入 Sa-Token 运行时保护，默认仅保留账号登录和健康检查为公开路径；Swagger 默认关闭，公开端点必须显式配置。
- 新增受控 CORS、安全响应头，并将 Flyway `baseline-on-migrate` 改为默认关闭，同时启用迁移校验、禁止 clean 和禁止乱序迁移。
- 新增初始化边界、登录限流、并发失败、接口保护、CORS 和安全响应头测试；本版本不新增数据库迁移，不连接真实 MySQL、Redis、RabbitMQ 或 MinIO。
- 产品版本递增至 `v0.0.148`。
